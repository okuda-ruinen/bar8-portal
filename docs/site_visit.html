BAR8 現地視察・オーナーヒアリング項目（事業DD編）

作成：2026-10-09　用途：次回の現地視察とオーナーヒアリングで、その場で埋める　分類：正本 使い方：数字は「本人の記憶」と「記録（POS・帳簿・請求書）」を分けて書く。記録で裏が取れたものだけ ✔ にする。許認可・賃貸借・消防は DD_許認可法務チェックリスト.md の A 節を併用。

1. 売上 KPI（月次・開業からの全期間）

# 項目 聞き方・見方
1-1 月商（開業〜直近月・月別） POS/レジ締め表・通帳入金・決済明細で裏取り。記憶値との差
1-2 営業日数・1日あたり売上の分布 平日/金土/祝前日。「最高日」「最低日」の金額と理由
1-3 客数・組数（1日平均・曜日別） 1人客比率、2〜4名、団体
1-4 客単価（ドリンク／フード別） 滞在時間との関係。チャージ料の有無と金額
1-5 時間帯別売上 開店〜22時／22〜0時／0〜1時。深夜帯の比率（深夜をやめた場合の影響）
1-6 常連比率・上位顧客 「名前で呼べる客」が売上の何割か。上位10人の来店頻度と月額。オーナー不在日の売上
1-7 来店動機 オーナー個人／ワイン／立地／価格／紹介。オーナー自身の見立て
1-8 季節性・イベント 忘年会期、GW、お盆、周年、台風や雪の影響
1-9 キャッシュレス比率 現金／カード／QR の比率と手数料率
1-10 売掛・ツケ・ボトルキープ ツケの残高と回収実績。キープボトルの本数と管理方法（承継対象の負債に近い）
1-11 貸切・イベント売上 件数・単価・取り方
1-12 値上げ・メニュー改定の履歴と反応 価格弾力性の手がかり

2. 原価・仕入・在庫

# 項目 聞き方・見方
2-1 ドリンク原価率・フード原価率 月次の仕入額÷売上。記憶値と請求書で突合
2-2 ワインの仕入先（卸・インポーター・酒販店）と条件 社名、担当者、掛け／現金、締め支払、最低ロット、配達頻度、名義変更の可否
2-3 ビール・スピリッツ・ソフトドリンクの仕入先 同上。サーバー貸与（ビール会社）の有無と条件
2-4 氷 製氷機か氷屋か。氷屋なら業者・納品頻度・単価
2-5 フード食材 仕入先（スーパー／業者）、頻度、仕込み担当、ロス率
2-6 在庫 現在の在庫リスト（本数・仕入値・購入時期）、デッドストック、保管状態（温度・直射日光）、棚卸しの頻度
2-7 消耗品 グラス・紙ナプキン・コースター・トイレ用品・洗剤の仕入先と月額
2-8 発注の仕組み 誰が・いつ・何を見て発注するか（感覚か、在庫表か）

3. 業者・サービス契約（名義変更が要るもの）

# 業者 聞くこと
3-1 おしぼり 業者名、納品頻度（週◯回）、本数、単価、回収方法、契約期間・解約条件
3-2 リネン・ユニフォーム 有無、業者、頻度
3-3 ごみ・産廃 事業系ごみの回収業者、頻度、月額、ビン・缶・生ごみの分別と置き場
3-4 グリストラップ・排水・厨房清掃 清掃頻度、業者か自分か、最終清掃日
3-5 害虫駆除 業者・頻度・最終実施日（4F雑居ビルは要確認）
3-6 音楽 BGMの出し方（配信サービス・CD・ライブ）、JASRAC/NexTone の契約有無と月額
3-7 決済端末 会社（Square・AirPAY・stera 等）、手数料率、入金サイクル、端末の所有・リース
3-8 POS・レジ 製品、月額、データのエクスポート可否（DDの裏取りに使う）
3-9 予約・集客サービス 食べログ・Google・Instagram 以外の掲載、有料プラン
3-10 通信 Wi-Fi 回線、固定電話、月額、契約者
3-11 水道光熱 電気・ガス・水道の契約者と月額（夏冬の差）、ビル一括か個別か
3-12 保険 店舗総合保険・火災・PL・休業補償の有無、保険会社、保険料、名義
3-13 警備・鍵 機械警備の有無、鍵の本数と所持者、ビルのオートロック・入退館時間
3-14 リース 製氷機・冷蔵庫・ワインセラー・食洗機・空調・音響・看板。リース会社・残期間・月額・残債・所有権
3-15 税理士・会計 顧問の有無、記帳方法（会計ソフト）、月額
3-16 その他定期支払 サブスク、看板使用料、ビル共益費以外の負担

4. 設備・物件（視察で実物を見る）

# 項目 見るポイント
4-1 席数・レイアウト カウンター席数、テーブル席数、立ち席。満席時の実際の収容。平面図との一致（深夜届出の平面図の下敷きになる）
4-2 厨房・バックヤード シンク数、冷蔵・冷凍、製氷機の製氷能力と年式、ワインセラーの容量と温度、食洗機
4-3 空調・換気 年式、効き、フィルター清掃、煙・匂い
4-4 給排水・トイレ 水圧、排水の流れ、トイレの数と状態、温水
4-5 電気容量 ブレーカー容量、落ちた経験
4-6 内装の状態 カウンター材、床、壁、照明。修繕が必要な箇所と見積もり
4-7 造作の所有区分 前テナントから引き継いだもの／現オーナーが作ったもの／ビル付帯。原状回復の線引き
4-8 看板・サイン 1F と 4F の表示、ビルの案内板、照明
4-9 防災 消火器の期限、誘導灯、火災報知器、避難経路、防炎カーテン（許認可編 E 節）
4-10 ビル共用部 エレベーターの年式・点検、階段、共用トイレの有無、他テナントの業種・営業時間、管理人
4-11 騒音・振動 上下階・隣との関係、音漏れ、過去の苦情
4-12 搬入動線 仕入・ごみ出しの動線、台車の可否、搬入時間の制限
4-13 携帯電波・Wi-Fi 4Fでの電波状況（決済端末が止まる店は多い）

5. 運営オペレーション（1日の流れを再現する）

# 項目 聞くこと
5-1 開店前 何時に入るか、仕込み内容と所要時間、清掃、氷・釣銭の準備
5-2 営業中 オペレーションの人数、ピーク時間、オーナーの立ち位置（カウンター内か客席か）
5-3 閉店後 レジ締め、現金の保管場所と持ち帰り、売上の記録先、清掃、戸締まり、終電・帰宅手段
5-4 現金管理 釣銭の額、金庫、銀行入金の頻度、誰が数えるか。差異が出たときの扱い
5-5 売上記録 POSか手書きか。日報の有無。見せてもらう
5-6 メニューとレシピ ドリンクメニュー（ワインリストの更新頻度）、フードメニュー、レシピの文書化の有無、オーナーしか作れないもの
5-7 仕入・発注の判断 誰が、どの頻度で、何を見て
5-8 予約の受け方 DM・電話・貸切の条件、ノーショー対応
5-9 クレーム・トラブル 酔客、無銭、会計トラブル、ケガ、警察対応の経験
5-10 衛生 検便・手洗い・グラス洗浄のルール、保健所の立入履歴
5-11 休業の判断 臨時休業の頻度と理由（Instagram の告知の多さは何を意味するか）

6. 人

# 項目 聞くこと
6-1 従業員・ヘルプ 人数、雇用形態、時給、シフト、勤続、承継後も残る意思。いない場合はオーナー1人で回している実態
6-2 オーナーの稼働 週何日・何時間店に立つか。立っていない日は誰が
6-3 引継ぎ 何か月・週何日同席できるか。常連への紹介の仕方。引継ぎ期間中の報酬の考え方
6-4 承継後のオーナーの関与 完全に退くか、たまに立つか、店長として残る選択肢はあるか
6-5 店長候補 知人・常連・スタッフに候補がいるか。相場観（固定給・歩合）
6-6 オーナーの体調・生活 売却理由の本音。急ぐ事情があるか

7. 顧客・集客・ブランド

# 項目 聞くこと
7-1 顧客像 年齢層、性別比、職業（国分町の飲食店従事者か、会社員か、観光か）、居住地
7-2 来店経路 紹介／Instagram／Google／通りがかり／他店からの流れ（2軒目需要）
7-3 Instagram 運用者、投稿頻度、DM での予約数、フォロワーの質。アカウント引継ぎの方法（メール・電話番号・二段階認証）
7-4 Google ビジネスプロフィール オーナー確認済みか、口コミ数と評価、引継ぎ
7-5 店名・ロゴ 「BAR8」の由来、ロゴデータの所在、看板や印刷物の権利
7-6 近隣との関係 同じビル・近隣店との付き合い、送客関係、町内会・振興組合への加入と会費
7-7 競合 オーナーが意識している店、客が流れる先
7-8 コンセプト オーナーが「変えてほしくないこと」「変えていいこと」

8. 財務・税務の記録（持ち帰る書類）

# 書類 備考
8-1 確定申告書・青色申告決算書（開業後の全期） 売上・経費の全体像
8-2 月次の売上記録（POS 出力・日報） 1 節の裏取り
8-3 仕入先ごとの請求書（直近6か月） 2 節・3 節の裏取り
8-4 通帳・決済明細（事業用） 入金の実態
8-5 借入・リース契約書、返済予定表 承継対象の債務
8-6 未払一覧（仕入・家賃・税・社会保険） 簿外の確認
8-7 固定資産・什器の一覧（購入時期・金額） 造作譲渡の対象リストの元
8-8 開業時の内装工事の見積・請求書 造作の価値と原状回復の目安

9. 視察当日のタイムテーブル（案）

  1. 営業前（明るい時間）：設備・バックヤード・ビル共用部を見る（4 節）。平面図と席数を実測
  2. ヒアリング（2〜3時間）：1→2→3→5→6→7 の順。数字は記録で裏取りしながら
  3. 営業中（できれば金曜か土曜）：客層・客単価・オペレーション・オーナーの立ち位置・深夜帯の入りを観察（1-5・1-6・5-2）
  4. 可能ならオーナー不在の営業日にも一度客として行く（売上剥落の見積もりの材料）
  5. 帰りに書類（8 節）を預かるか、写真で控える

10. 視察後に決めること

  • 「オーナーが抜けても残る売上」の見積もり（1-6・1-7・6-2 から）
  • 運営体制の案（誰が立つか・店長の要否）
  • 引き継ぐ契約と切り替える契約の仕分け（3 節）
  • 修繕・更新が必要な設備と概算（4 節）
  • 譲渡契約書に載せる資産リストの元（8-7）
