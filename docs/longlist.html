最初に押さえること：個人事業主の店を買う＝会社を買うのではなく、資産（内装・什器・在庫）と契約上の地位（賃借権・取引先）と営業権（屋号・SNS・常連）を個別に引き継ぐ「事業譲渡」になる。許認可は、飲食店営業許可は2023-12-13以降の全部譲渡なら「地位承継届」で引き継げる。深夜酒類提供の届出は引き継げず譲受側が新規届出。詳細は DD_許認可法務チェックリスト.md。

1. 目的と前提（主たる承継者が最初に決める）

  • 目的：承継者の拠点として店を継続する。投資利回りや多店舗展開は現時点では主目的としないが、将来の選択肢として排除しない
  • 誰が店に立つのか：承継者が日常的に店に立てないなら、「雇われ店長」か「現オーナーの残留」が前提になる。遠隔オーナー型の小規模バーは、現金管理と人の離脱が最大リスク
  • 現オーナーが売る理由（本音）：体力・資金・転居・不採算。理由によって「売上の再現性」の見立てが変わる
  • 時間軸：いつまでに決めるか、クロージング希望日、引継ぎ期間
  • 撤退条件：いくらまでなら失ってよいか（上限額）を先に決める

2. スキーム（買い方の設計）

  • 承継スキーム（最重要論点）：主たる承継者が株式会社ティーツーシー（以下 T2C）であることを前提に、次の2案を比較して決める
  • 案A：T2C 本体で事業を譲り受ける。飲食店営業許可の譲受人・賃貸借の名義人・深夜酒類提供の届出者はいずれも T2C。利点＝設立コストと手続きが最小、既存法人の信用と口座を使える。論点＝定款の事業目的に飲食業の追加（登記）、建設業の本業と飲食業が同一法人に同居することの信用・税務・労務上の影響、店の損益が本体決算に直結、飲食業の責任（食中毒・事故）が本体に及ぶ
  • 案B：T2C が子会社（新設法人）を設立し、そこで譲り受ける。他の出資者（オーナー候補）が子会社に出資・参画できる。利点＝本業とのリスク分離、出資者の持分設計が可能、将来の売却・撤退が切り分けやすい。論点＝設立費用（合同会社なら登録免許税6万円〜・株式会社なら約20万円〜）と維持費（法人住民税均等割 年7万円〜・税理士）、資本金と親子の出資比率、役員構成、株主間（社員間）契約（意思決定・追加出資・退出・持分譲渡・競業避止）、子会社の信用が無いため賃貸人が親会社の連帯保証を求める可能性、許認可はすべて子会社名義で取得
  • 判断基準＝①他の出資者を入れるか（入れるなら案B）②本業との分離をどこまで重視するか ③賃貸人が受け入れやすいのはどちらか ④設立・維持コストを、対価が大きくない案件で負担する価値があるか
  • どちらでも譲受人は法人になるため、保健所に「法人への譲渡で地位承継が使えるか」を最初に確認する（DD 許認可編 B3）
  • 出資者間の取り決め（案Bの場合）：出資比率、意思決定（日常／重要事項）、追加出資義務、利益分配、退出ルール（持分の買取り価格の決め方）、競業避止を設立時に書面にする
  • 譲渡の形：事業譲渡契約（資産・契約・営業権の個別承継）＋賃貸借契約の名義変更（または新規契約）＋許認可の新規取得
  • 現オーナーの関与：引継ぎ期間（例：3か月は週◯日同席）、残留して店長として雇うか、完全退出か
  • 資金：自己資金／日本政策金融公庫（創業・事業承継）／自治体の事業承継補助の有無【要確認】

3. デューデリジェンス（DD）の中身

3-1. 財務・税務

  • 月次の売上・客数・客単価（開業からの全期間。開業が2025-08なら1年強分しかない＝季節性の検証が弱い点を認識）
  • 現金商売の実態確認：POS／レジ記録、銀行入金、キャッシュレス決済の明細、仕入の請求書。申告書と実態の差を見る
  • 原価率・FLコスト（食材酒類原価＋人件費）、家賃、水光熱、通信、SNS広告、消耗品
  • 確定申告書（開業後の全期分）・青色申告決算書・帳簿
  • 在庫：ワイン・酒類の在庫リスト、評価（仕入値・劣化・デッドストック）
  • 債務：リース（製氷機・冷蔵庫・POS等）、借入、未払（仕入先・家賃・税）
  • 売上の「人」依存度：常連の比率、来店理由。一人営業のため不在日の実績は無く、オーナーが抜けた後の売上剥落は常連の来店理由から見積もる。これがバリュエーションの核

3-2. 法務・契約

  • 賃貸借契約書：契約者名義、期間・更新、賃料・共益費、保証金と返還条件、譲渡・転貸の禁止条項と名義変更の可否（オーナー承諾）、用途制限（深夜営業・バー可か）、原状回復義務、解約予告
  • ビル：小野ビルの管理状況、他テナント（風俗・トラブル）、エレベーター・消防設備、建物の築年
  • 取引先契約：酒類卸、食材、音楽（JASRAC等の利用許諾）、決済端末、予約サイト
  • 屋号・商標・SNS：BAR8 の名称使用権、Instagram アカウントの引継ぎ（運用ルール・パスワード・本人確認）、Google ビジネスプロフィール
  • 従業員：雇用の有無、雇用契約・労務（社会保険・労働時間）、承継するか
  • 訴訟・クレーム・近隣トラブルの有無
  • 現オーナーの競業避止（期間・地域＝国分町周辺）と顧客持ち出しの防止

3-3. 許認可・コンプライアンス（引き継げない前提）

  • 飲食店営業許可（保健所）：2023-12-13以降の事業譲渡（営業の全部）は「譲渡による地位承継届」で承継可（仙台市 様式第8号・譲渡契約書の写し添付）。法人への譲渡の可否は青葉区衛生課に要確認。食品衛生責任者の選任
  • 深夜酒類提供飲食店営業の届出（警察署）：0時以降に酒類を提供するなら必須。営業者に紐づくため承継不可＝譲受側が営業開始10日前までに新規届出（飲食店営業許可証の写しが必要＝保健所の承継が先）
  • 風営法の該当性：「接待」（客の隣に座って談笑等）があると風俗営業（1号）許可が必要になり、話が別物になる。現状の営業実態を確認
  • 消防：防火管理者（収容人数による）、防火対象物使用開始届、避難経路
  • 酒類販売業免許：店内提供は不要。持ち帰り販売・通販をするなら必要
  • 税務：開業届／法人設立届、消費税（インボイス登録の要否）、償却資産
  • 看板・騒音・ごみ等の条例

3-4. ビジネス・商圏

  • 国分町・定禅寺通りの商圏、同業（ワインバー）の密度、4F雑居ビルの集客ハンデ
  • 客層（年齢・常連比率・観光客）、来店動機（オーナー個人／ワインの品揃え／価格）
  • SNS 以外の集客導線（口コミ・紹介・予約サイト）
  • 価格帯と原価、提供メニューの再現可能性（オーナーの技量に依存するか）
  • 「居抜き物件として借りた場合」との比較：同条件の居抜きがいくらで借りられるかが、営業権に払う価格の上限を決める

3-5. 物件・設備

  • 内装・什器・設備の所有者（オーナー所有か、前テナントからの造作か、リース品か）
  • 造作譲渡の対象リスト、老朽化と更新費用（製氷機・冷蔵庫・空調・給排水）
  • 原状回復の範囲と見積もり（退去時コストは買収時点で把握）

3-6. 人・運営

  • 現オーナーの引継ぎ可能期間・意欲
  • 店長候補の有無（現スタッフ・知人・採用）、報酬設計（固定＋歩合）
  • 遠隔管理の仕組み：POS・キャッシュレス比率の引き上げ・日次報告・棚卸し

4. 価格の考え方

  • 小規模バーの譲渡価格は「造作譲渡料＋在庫＋営業権」。営業権は売上の再現性次第で、オーナー個人に紐づく常連売上は原則ゼロ評価に近い
  • 目安はあるが相場は幅が大きい。「同条件の居抜き物件の取得費」と「現オーナー抜きで再現できる月次利益×回収したい月数」の二つから上限を置く【推定・相場は要調査】
  • 価格調整条項：引継ぎ期間中の売上実績で一部後払い（アーンアウト的な設計）にできると、売上剥落リスクを売主と分担できる

5. 契約（事業譲渡契約の論点）

  • 譲渡対象の特定（資産リスト・契約・屋号・SNS・レシピ・顧客情報の扱い）
  • 表明保証（簿外債務なし、許認可上の違反なし、賃貸人の承諾取得）
  • 引継ぎ義務（期間・内容）、競業避止、従業員の扱い
  • 対価と支払条件（手付・残金・価格調整）、クロージング条件（賃貸人承諾、許認可の目処）
  • 解除・損害賠償、秘密保持

6. 収支計画（買収後3年）

  • 初期：譲渡対価、許認可費用、名義変更費用、保証金差替え、運転資金（3か月分）、法人設立費
  • 月次：売上シナリオ（現状維持／オーナー離脱で▲30%／施策後）、固定費、店長人件費、役員報酬の有無、案Bなら子会社の維持費
  • 損益分岐売上と、撤退ライン（何か月連続赤字で止めるか）

7. タイムライン（案）

  1. 主たる承継者が目的・上限額・運営体制・承継スキーム（案A／案B）を決める（本書 §1〜2）
  2. 売主へ資料依頼（§9のリスト）、秘密保持の取り交わし
  3. 現地確認（営業日の客入り・ビル）
  4. DD（§3）→ 価格提示 → 基本合意
  5. 賃貸人への打診・承諾、許認可の事前相談（保健所・警察署）
  6. 事業譲渡契約の締結、法人設立、許認可申請
  7. 引継ぎ期間 → クロージング → 名義変更・届出完了

8. リスク一覧（優先順）

  1. オーナー離脱後の売上剥落（常連依存）
  2. 賃貸人が名義変更を認めない／条件が変わる
  3. 遠隔オーナーによる現金管理・人の離脱
  4. 風営法の該当性の誤認（接待があれば別許可）
  5. 案Bで出資者間の取り決めが無いまま進むこと／案Aで本業と飲食業のリスクが混ざること
  6. ビル・設備の老朽化と退去コスト
  7. 開業1年強でデータが薄く、季節性・持続性が読めない

9. 売主への資料依頼リスト

  • 確定申告書・青色申告決算書（全期）、月次売上・客数（開業以来）、POS/決済明細、仕入請求書
  • 賃貸借契約書（原本）、保証金預り証、ビル管理規約
  • 許認可関係（飲食店営業許可証、深夜酒類提供届出控え、消防関係）
  • 資産リスト（内装・什器・設備・在庫）、リース契約、借入契約
  • 従業員の雇用契約、シフト実績
  • SNS・Google ビジネスプロフィールの管理権限情報（引継ぎ方法）
  • 売却理由と希望条件（価格・時期・引継ぎ可能期間）

10. 未確認事項（取得でき次第更新）

  • 営業時間（深夜営業の有無）、席数、開業日の確定
  • 現オーナーの売却理由・希望価格
  • 賃貸借の名義変更可否
  • 風営法の該当性（接待の有無）
  • 承継スキーム（案A本体／案B子会社）の選択と、案Bの場合の出資者・比率・役員／店に立つ人と店長候補の有無

11. Go／No-Go の関門

  • 賃貸人の承諾が得られない → No-Go
  • 風俗営業に該当し許可取得が現実的でない → No-Go
  • オーナー個人に紐づく売上を除いた見込みが損益分岐を大きく下回り、店長を置いても埋まらない → 価格を造作譲渡相当まで下げるか No-Go
  • 承継スキームと運営体制（誰が店に立つか）が決まらない → 着手しない
